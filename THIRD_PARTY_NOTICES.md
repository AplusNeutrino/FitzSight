# Third-Party Dependencies

FitzSight is released under the MIT License. Third-party packages remain subject to their own licenses and terms.

Core/runtime dependencies currently include:

- DuckDB
- NumPy
- pandas
- SciPy

Optional integrations currently include:

- OpenAI Python SDK
- Streamlit
- python-pptx (submission asset generation)
- Pillow (offline backup-video frame generation)

LibreOffice is used as an external build tool to export the submitted PPTX to PDF when available; FFmpeg is used as an external build tool to encode the optional offline MP4 backup. Neither tool is bundled with this repository.

The project does not redistribute model weights or competition-provided private datasets. Before a final competition submission or binary/container redistribution, re-check the exact dependency versions and their upstream license notices generated by the deployment environment.

No API key, customer PII, former-employer dataset, or confidential CRM export should be committed to this repository.
