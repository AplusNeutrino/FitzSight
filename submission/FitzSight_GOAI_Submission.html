PLANNER OUTPUT = UNTRUSTED INPUT

DeepSeek 在系统中负责什么

DeepSeek 只负责选择获准的 intent 和 action 顺序。权限控制、SQL、数值计算和结论核验都留在本地。

01Intent Gate网络调用前拒绝目录外问题
02Constrained PlannerFlash / Pro 白名单 · JSON purpose
03Deterministic Tools只读 SQL · 统计 · 分解 · falsification
04Verifier GateEvidence · digest · status · causal wording
EVIDENCE REGISTRY每个数字、状态与主张都有稳定 Evidence ID
PLANNER CAN选择批准 intent / action 顺序
PLANNER CANNOT生成任意 SQL · 计算数字 · 执行金融动作 · 决定最终结论
