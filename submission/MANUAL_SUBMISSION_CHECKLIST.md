# FitzSight — Manual Submission Checklist

**Owner:** User  
**Execution mode:** Manual only

The repository and handoff scripts prepare files; they do not perform these external actions.

## A. Before opening the portal

- [ ] Keep `FitzSight_Manual_Handoff.zip` locally.
- [ ] Keep `FitzSight_GOAI_Initial_Round.pdf` and `.pptx` locally.
- [ ] Keep the offline HTML and MP4 backup locally.
- [ ] Keep the repository URL ready: `https://github.com/AplusNeutrino/FitzSight`.
- [ ] Run `python scripts/preflight_submission.py` and confirm PASS.
- [ ] Optionally run `python scripts/runtime_doctor.py` on the final demo machine.

## B. Portal fields — manual user action

- [ ] Open the official GOAI portal yourself.
- [ ] Re-check the portal's current character/file-size/format limits.
- [ ] Enter project name: **FitzSight**.
- [ ] Select the correct track: **Boundless Agents · AI+金融**.
- [ ] Paste the appropriate project introduction from `PORTAL_COPY.md`.
- [ ] Enter the public repository link.
- [ ] Upload the requested PPT/PDF.
- [ ] Upload or link the optional demo/video if the portal supports it and you want to include it.
- [ ] Review all rendered fields and uploaded filenames yourself.

## C. Actual submission — manual user action

- [ ] Click the portal's final submission/confirm button yourself.
- [ ] Confirm the portal reports success.
- [ ] Save a screenshot of the confirmation page yourself.
- [ ] Save any confirmation email/receipt yourself.
- [ ] Record the submission time and any project/submission ID.

## D. After submission

- [ ] Copy the final submitted assets to a second local/cloud location you control.
- [ ] Keep the repository commit used for submission recorded.
- [ ] Do not change competition-facing numeric claims without regenerating the deck from verified runtime output.
- [ ] If the portal allows later edits, treat those edits as a separate manual action and retain new confirmation evidence.

## Boundary

Unless you explicitly request a specific external action, ChatGPT/FitzSight automation should stop at preparation, validation, packaging, and instructions. It should not access Gmail or the submission portal on its own.
