## Ground-truth leakage check

The deterministic investigation queries only:

- `lead_created_at`
- `region`
- `assigned_team`
- `response_time_minutes`
- `converted_ftd`

The evaluation-only `affected_by_crm_change_gt` field is not referenced in normal investigation SQL. The automated investigation test asserts that SQL evidence contains no `_gt` field reference.

## SQL safety tests

Automated tests verify rejection of:

- DROP;
- UPDATE;
- multi-statement SQL;
- external `read_csv_auto(...)` access;
- SQL comments in Agent-generated queries;
- PRAGMA.

The Tool also blocks broader mutation/configuration/external-scan keyword/function sets in code.

## Deployment validation required

After the user deploys the package, run:

```bash
pip install -e ".[dev]"
pytest -q
python scripts/investigate.py --backend duckdb
```

Only after this succeeds should the DuckDB runtime validation tracker item be changed from `in_progress` to `done`.
