## Compact evidence validation

The customer-feature SQL result contains 6,770 European rows. v0.6 returns the full bounded result to the deterministic segmentation Tool but stores only a bounded preview plus the full-result digest in the audit registry. The generated structured-planner sample is approximately 68 KB rather than a multi-megabyte raw-row audit payload.

## Evaluation boundary

Normal segmentation SQL does not query `customer_segment_gt` or any other `*_gt` field. The benchmark-only hidden labels remain outside Agent execution.

The derived customer segments are descriptive operational groups and must not be interpreted as:

- credit scores;
- AML classifications;
- suitability decisions;
- eligibility decisions;
- adverse-action recommendations.
