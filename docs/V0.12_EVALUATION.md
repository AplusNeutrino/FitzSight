# FitzSight v0.12 — Evaluation v2

v0.12 adds evaluation designed to answer two questions that the fixed five-scenario benchmark cannot answer by itself:

1. Does the bounded system remain stable on unseen synthetic seeds and paraphrased questions?
2. Does the EvidenceClaimVerifier / evidence gate materially change unsafe output behavior?

## Holdout seed + paraphrase robustness

Runner: `scripts/run_evaluation_v2_holdout.py`  
Evidence: `docs/V0.12_HOLDOUT_RESULTS.json`

Protocol:

- excludes the showcase/fixed benchmark seed `20260811`;
- uses holdout seeds `20260821` and `20260831`;
- evaluates the CRM/FTD hero and false-correlation refusal workflows;
- uses two paraphrases per workflow per seed;
- records routing stability, verification status, root-cause/support status, evidence coverage, and false-correlation refusal correctness.

Observed v0.12 build result:

```text
8 case runs
intent routing stability:                100%
verification pass rate:                  100%
mean evidence coverage:                  100%
false-correlation refusal correctness:   100%
supported-candidate rate:                 75%
```

The 75% supported-candidate rate is intentionally reported rather than “corrected away”: on one holdout CRM seed the evidence did not meet the bounded attribution threshold, so FitzSight returned `insufficient_evidence` while verification still passed. This is a useful fail-closed behavior, not evidence of 100% root-cause recovery across arbitrary synthetic draws.

## Controlled architecture ablation

Runner: `scripts/run_evaluation_v2_ablation.py`  
Evidence: `docs/V0.12_ABLATION_RESULTS.json`

Protocol compares the same six deterministic fixtures under:

- **Full FitzSight:** EvidenceClaimVerifier controls answer emission.
- **No-verifier-gate ablation:** supported-status claim text is passed through without the verifier/evidence output gate.

This is a controlled architecture ablation, **not** a Generic LLM baseline. No live-provider performance or cost is inferred.

Observed result:

```text
Full FitzSight
  safe-control acceptance:                100%
  adversarial refusal correctness:        100%
  unsafe answer rate on adversarial:        0%
  unsupported causal claim emission:        0%
  emitted-output mean evidence coverage:  100%
  detected verifier violations:              4

No-verifier-gate ablation
  adversarial refusal correctness:          0%
  unsafe answer rate on adversarial:       100%
  unsupported causal claim emission:      16.7%
  emitted-output mean evidence coverage:   66.7%
```

## Scope boundary

These are synthetic, deterministic competition evaluations. They do not establish real-client business impact, regulatory fitness, or production model performance. Generic LLM / LLM+SQL baselines remain unreported until a real, fair, explicitly opted-in provider experiment is executed.
