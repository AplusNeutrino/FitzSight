## Safety tests

v0.4 automated tests explicitly verify that:

- unrelated stock-picking questions are refused;
- unsupported intent is rejected before calling the external planner callback;
- unknown actions such as `execute_trade` are rejected;
- planner purposes containing executable SQL are rejected;
- malformed planner JSON is rejected;
- missing Evidence IDs cause verifier failure;
- causal overclaims cause verifier failure;
- structured planner output cannot bypass deterministic SQL/evidence execution;
- evaluation-only `_gt` fields remain outside normal Agent SQL.
