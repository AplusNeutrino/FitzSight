# FitzSight v0.10 Validation

## Scope

v0.10 validates operator handoff and manual submission boundaries. It does not claim that an external competition portal, Gmail, Streamlit, or OpenAI runtime was used unless separately evidenced.

## Required assertions

1. manual handoff packet can be built entirely locally;
2. the packet contains the prepared PPT/PDF, portal copy, offline demo/video, evaluation/compliance summaries, and user instructions;
3. generated metadata explicitly records `external_submission_performed=false` and `network_actions_performed=false`;
4. submission preflight validates the manual handoff ZIP;
5. generated data and secrets are absent from the packaged release;
6. existing analytical benchmark/adversarial behavior remains unchanged.

## Manual-only external steps

The following are intentionally outside automation:

- actual GOAI portal upload/submission;
- portal confirmation capture;
- Gmail/email confirmation access;
- final-machine Streamlit health-check;
- optional OpenAI live validation;
- timed human rehearsal.

See `docs/OPERATOR_BOUNDARY.md`.
