## 1. Industry scenario value — PASS

**Primary user:** Brokerage / FinTech Operations Analyst.  
**Beachhead chain:** acquisition → FTD conversion → client-fund flows.

The hero question is concrete and operational: “Why did European FTD conversion deteriorate after July 15?” The deck explains the current manual pain (cross-table diagnosis, statistics, contribution analysis and event/document evidence) and keeps Regional/Sales Operations Manager as a secondary consumer rather than broadening the first-use persona.

## 2. Agent capability and task loop — PASS

The judge-facing path shows:

```text
user question
→ local approved-intent gate
→ constrained plan
→ deterministic contribution/statistics
→ result-conditioned approved drilldown
→ operational event + document Evidence
→ EvidenceClaimVerifier
→ verified decision-support answer
→ approved evidence-only follow-up
```

The failure branch is also explicit: dependency error → error Evidence → no document corroboration → `insufficient_evidence` → verified bounded answer. Planner/model output still cannot generate arbitrary SQL, arbitrary tool parameters, file paths or high-impact financial actions.

## 4. Technical implementation depth — PASS

Evidence includes read-only SQL/Python analytics, statistics, contribution decomposition, anomaly detection, constrained intent/action routing, append-only Evidence Registry, source-addressable synthetic operational documents, fail-closed EvidenceClaimVerifier, deterministic fallback, five-workflow benchmark, adversarial release gate, unseen-seed/paraphrase holdout and controlled architecture ablation.

The no-verifier/evidence-gate comparison is labeled an **architecture ablation**, not a Generic LLM baseline. OpenAI live-provider validation remains optional and unverified unless explicitly run with a configured provider.

## 5. Safety, compliance and traceability — PASS

- Competition data are synthetic; no real customer PII or employer-confidential dataset is included.
- Important supported claims map to Evidence.
- Causal overclaim, `_gt` leakage, unsupported scope and false-correlation behavior are release-gated.
- FitzSight does not provide investment advice, execute trades/transfers, freeze accounts, or make AML/credit/suitability/adverse-action decisions.
- Competition language is **“Autonomous investigation. Human decision.”**
- RBAC, row/field policies, PII masking and retention are documented as **production blueprint**, not current PoC implementation.
