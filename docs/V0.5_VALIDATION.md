## OpenAI provider validation

A fake Responses client validates that the provider:

- uses the configured model;
- calls `responses.create`;
- requests `text.format.type = json_schema`;
- sets `strict = true`;
- restricts intent to the locally classified intent;
- sets `store = false`;
- passes the returned JSON through the same local `validate_plan` policy;
- is not invoked for unsupported questions.

A **live** OpenAI request is not claimed in this build because no user credential is available.
