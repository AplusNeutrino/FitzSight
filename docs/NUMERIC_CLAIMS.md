# 数值声明迁移：净入金变化与分解契约

本轮只覆盖净入金调查的 **N-C1、N-C2、N-C3、N-C4**，不是所有报告数字都已经核验。其他 N-C5、转化率、营销和分群声明仍沿用旧检查；M1-02 总项保持进行中。

`Claim.numeric_binding` 对 N-C1/N-C2 必须存在，包含指标标识 `net_deposit_change.v1`、数值、金额单位、USD、Europe、四个日期边界和证据 ID/字段。旧 Claim 可不带绑定，以支持逐条迁移，但净入金计划必须分别恰有一个 N-C1 和 N-C2，不能通过删掉绑定/声明逃过检查。

当前契约固定为合成演示的 USD、Europe 和现有日期口径，未实现通用 MetricDefinition 或跨地区/时期请求。文字由 `render_net_change` 统一生成；核验器要求文字与绑定渲染完全一致，避免结构化值正确而自由文字写错。

核验步骤：

1. 确认绑定类型、指标/字段/单位/币种/区域白名单，以及有限且非布尔的数值。
2. 确认证据引用、工具类型、成功状态及现有结果摘要。
3. 与分解证据中的金额、币种、区域及四个时间边界比较。
4. 从四份原始 SQL 结果按 baseline deposit/withdrawal、current deposit/withdrawal 顺序重算 `(current deposits - current withdrawals) - (baseline deposits - baseline withdrawals)`，并检查四份引用及摘要。
5. 用绝对容差 1e-8、相对容差 0 比较未格式化金额；呈现保留两位小数。模板文字也必须一致。

净入金的现金流查询现在读取 currency，遇非 USD 直接拒绝，不把其他币种金额静默标成美元。该检查不实现汇率换算。

## 验证与边界

[RUN-05](validation/2026-10-27-run05.md) 记录手算小样本、数值/单位/币种/日期/字段/引用篡改、中文错误文字、绑定/声明删除和错误分解重算反例，以及实际引擎回归。Mock 的非 USD 拒绝测试只证明分支行为，不代表真实外部数据接入。

证据工具和执行代码仍是信任边界：当前摘要不是签名，参数没有独立不可篡改保护；此核验不证明 SQL 符合请求、未截断、原始流水没有重复、财务状态定义正确或数据快照可信。重算来自工具结果，不是重查源数据。时区、金额定点化、快照和数据契约仍待后续 M1/M2/M4；一般性的“合法 ID + 错数字”P0 尚未整体关闭。

## RUN-08：N-C3 来源重算

ConcentrationBinding 绑定比例（ratio，不是百分数）、分子/分母金额、USD、
Europe、前N客户数、起始时刻与不含末端的结束时刻、集中度证据字段及本期提款
明细证据。净入金计划必须恰有一个N-C3，绑定不能删除。
校验按明细customer_id重新聚合，再取金额最大的N个客户，不信任排名SQL的汇总数字。
分子/分母容差为1e-8，比例为1e-12，均无相对容差；文字必须与模板完全一致。
正常比例要求supported；零分母要求null、unavailable及insufficient_evidence。

此契约拒绝来源中的负数、非有限值及非USD；完整数据契约与跨币种仍待M2。
时间窗、区域和客户数与工具参数比较，参数本身未签名，尚未验证SQL过滤、截断、
请求授权与快照；不将此重算声称为独立源系统对账。其他声明与通用MetricDefinition、
UI标识仍待办。[本轮证据](validation/2026-10-28-run08.md)。

## RUN-10：N-C4 SQL聚合证据绑定

RegionalBinding保存两期每个地区的存款、提款、客户数，以及目标变化、对照中位数、
金额/客户单位、USD、Europe、四个日期边界和四份SQL聚合来源。核验从这些SQL结果
重新计算两期人均净额之差和非目标地区中位数，比较绑定、派生证据、状态及模板文字；
净入金计划必须恰有一个N-C4。金额绝对容差1e-8，相对容差0。
缺目标/对照地区保持null和insufficient_evidence，不能通过删除绑定逃过检查。

区域查询同时统计已完成且在窗口内的非USD/缺币种流水，发现后拒绝，不做汇率换算。
本批重算起点是SQL聚合结果，不是重新查询流水和客户主表；COUNT DISTINCT、
JOIN完整性、过滤、截断和历史客户快照仍属于工具/数据契约边界。
当前客户分母仍是当前表，不能声称历史同期客户基数已实现。

## N-C5 事件措辞边界（RUN-20261028-11）

N-C5仅陈述欧洲、指定事件类型、附近半开时间窗口内是否检索到运营日志。未匹配时输出“未找到”，并明确这不证明现实中没有事件；匹配时也不把日志单独当作提款驱动或原因的证据。空日志、类型/地区/窗口不符以及存在事件但现金流全零的合成CSV在两个后端实际导入测试。

本次只修复引擎生成的文字；verifier尚未独立重算N-C5事件匹配、检查唯一声明或拒绝事后篡改。M1-02b-4b保持待办，不能将报告的verified状态解释为N-C5完整事实契约通过。
