## Slide 2 — The problem

Brokerage / FinTech Operations Analysts have dashboards, SQL and BI, but “why did this KPI change?” still creates a manual investigation across acquisition → FTD → client-fund flows:

```text
find tables → define KPI → compare periods → drill dimensions → test significance
→ inspect events → reconcile numbers → write report
```

A generic LLM can produce an explanation faster, but not necessarily a correct or auditable one.

## Slide 3 — The product

FitzSight converts a business question into an auditable investigation.

```text
Question
→ constrained plan
→ deterministic tools
→ evidence graph
→ verifier
→ verified answer
```

The model plans. SQL/Python calculate. The verifier controls what can be presented.

## Slide 9 — Why it is technically different

Four boundaries:

1. Local intent gate before model call.
2. Planner can only emit approved high-level actions.
3. Read-only SQL/Python own every number.
4. Every supported claim must pass EvidenceClaimVerifier.

If verification fails, FitzSight withholds the analytical answer.

## Slide 10 — Evaluation and reproducibility

```text
5 fixed benchmark scenarios / 5 PASS
8 holdout seed/paraphrase runs / 100% routing stability
100% holdout verification pass / evidence coverage
100% false-correlation refusal correctness
75% holdout supported-candidate rate (one CRM seed correctly insufficient)
```

Adversarial release gate:

```text
8 cases / 8 PASS
100% scope refusal
100% planner-policy catch
100% causal-overclaim catch
100% ground-truth-leak catch
```

Also show the controlled no-verifier-gate ablation: Full FitzSight refuses 100% of adversarial fixtures; removing the gate emits 100% unsafe adversarial answers. This is an architecture ablation, not a Generic LLM baseline. Show public repository, benchmark catalog, test suite, and deterministic fallback.

## Slide 12 — Why FitzSight matters

Existing BI answers **what** happened.

FitzSight autonomously investigates **why the measurable evidence changed**, while preserving an audit boundary between evidence and speculation. The authorized operator still makes the business decision.

> Not “chat with your CSV.” A reproducible financial investigation you can inspect, verify, challenge—and sometimes refuse.
